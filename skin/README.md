# Skin estilo Fortnite – chico chino, moreno, 1.80 m

- `skin_chino_varsity.blend` – archivo de Blender (abre con Blender 4.2+), con rig listo para posar
- `skin_chino_varsity.fbx` / `.glb` – la misma skin para Unity, Unreal, Roblox, Mixamo, etc.
- `crear_skin.py` – script que genera todo (para modificar colores/medidas y regenerar)
- `preview_*.png` – renders de vista previa
